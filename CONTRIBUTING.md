# Contributing

Thanks for considering contributing! We welcome all quality contributions, including AI-generated PRs.

## Quick Guidelines

- **New Features:** Please submit an Issue tagged with the `enhancement` label before opening a Pull Request so we can discuss it first.
- **Small Fixes & Bugs:** Feel free to open a Pull Request directly!
- **Setup Help:** Check out our [Developer Documentation](docs/dev/README.md) if you need help.

Hope you have a great day!
